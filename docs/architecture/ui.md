# 界面层

批次 05 已实现共用工作台。运行和离线验证步骤见 [网页与 Windows 工作台](../development/web-and-windows.md)。

## 统一资源

`ui/src/` 存放 HTML/原生 JavaScript，`ui/styles/` 存放 CSS，`ui/assets/` 存放本地图片、图标等资源。Windows 和 Web 共用尽可能多的资源；差异由独立平台适配处理。第一阶段不引入大型前端框架。

必要资源不得来自 CDN、在线字体、远程图片或远程脚本。使用相对路径，适应 GitHub Pages 的仓库子路径。构建产物与源码分离，网页输出至 `dist/web/`。

## 计划交互

主控制台包含左侧导航、顶部工具栏、模块卡片、全局搜索、设置、任务状态、日志入口、版本和通知。支持深浅主题、窗口缩放、导航返回与键盘访问。文件管理中心提供已授权文件的本地浏览与校验，数据工坊提供本地 CSV 转换。其余中心标记“计划中 / Coming Soon”。

界面展示的模块、任务、日志和平台能力必须来自真实状态。尚无底层能力时使用明确说明或禁用状态。设置变更、错误、进度和完成状态需提供可见反馈。

## 接口与安全

通过应用通信协议调用核心或平台，不在 UI 内隐藏任意本机调用。校验不可信输入，避免将用户内容拼入 HTML 执行上下文。消息边界由宿主再次检查，前端禁用按钮不能充当权限控制。

## 离线与验收

网页提供 manifest 与内容哈希版本化的 Service Worker，仅预缓存应用静态文件。浏览器验证在本机子路径加载后关闭服务器、模拟断网并重载。Windows 宿主须在 SDK 和 Runtime 可用时另行编译与运行验证。
