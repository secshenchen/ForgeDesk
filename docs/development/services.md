# 基础服务

## 应用路径

`AppPaths::resolve` 接收平台或调用者提供的绝对安装、用户数据及临时目录，并推导配置、缓存、日志及实验数据目录。可逐项覆盖配置、缓存、日志和实验数据路径。便携模式省略用户数据目录时使用安装目录下的 data 子目录。解析只做词法规范化，不创建目录或解析符号链接。应用负责选择具备访问权限、专用于本应用的数据根。

## 日志

`Logger` 接受专用日志目录、单文件字节上限、最低等级及控制台流。同一个实例串行写入，控制台流须比实例存活更久。输入使用 UTF-8，记录带 UTC 时间及级别，换行转义为可见字符。每条记录写完关闭文件。达到上限时把当前日志轮换为 `forgedesk.log.1`，保留当前文件和一份归档。超限记录返回错误。不得让多个进程或实例共享同一日志目录。

## 配置

`SettingsStore` 是由单一线程管理的配置快照，最多读取或保存 1 MiB。文件采用无 BOM 的 UTF-8，支持 LF 或 CRLF。空行和以 `#` 起始的行忽略。键为非空 ASCII 字母、数字、点、下划线或短横线，区分大小写。值前缀 `s:`、`i:`、`b:` 分别表示字符串、十进制有符号 64 位整数和 `true` / `false`。字符串支持反斜杠及 n、r、t 转义，保留空格。文件不支持行尾注释。

重复键、非法转义、整数溢出或格式错误使整次加载失败，内存旧快照保留。查询缺失键或不同类型时返回调用者给定的默认值。用 `set` 显式修改键。

保存使用应用专有目录中同级的 `.new` 文件，检查写入和关闭结果，保留上一份 `.bak`，再重命名替换。失败会返回错误，可能留下 `.new` 供检查。恢复时可显式加载 `.bak`。同一配置文件需要单写者，目录不得由不可信进程同时修改。

## 后台任务

`TaskManager` 接受 1 到 64 个工作线程和最大排队数。提交返回 TaskId。任务可使用上下文发布单调进度，检查 stop token 并协作退出。snapshot 返回当前状态，wait 通过条件变量通知终态或超时，forget 释放已完成记录。任务错误和异常转换为失败结果。排队取消不执行任务体，运行取消由任务在安全点完成。

关闭停止接收任务，取消排队任务，请求运行中的任务停止，并等待线程退出。任务不得保留上下文或从池内调用 shutdown。调用者在外部所有者线程关闭或销毁管理器，并确保任务不会无限阻塞。任务池在原生目标编译，Web 适配阶段单独处理浏览器线程限制。
